# Xan Finance

แอปวางแผนการเงินส่วนตัวแบบ Offline สำหรับ Android และใช้คนเดียว

## ฟังก์ชันที่มีในตอนนี้

- บันทึกรายรับ/รายจ่ายพร้อมวันที่และหมายเหตุ
- Dashboard รายเดือน: รายรับ รายจ่าย เงินเหลือ/ขาด
- งบประมาณและ progress ของค่าใช้จ่ายหลัก
- เงินสำรอง 10,000 บาท, 6 เดือน และ 12 เดือน
- หนี้มือถือ กีตาร์ และ กยศ.
- แก้เงินเก็บปัจจุบันจากหน้า ตั้งค่า
- Dashboard เลือกสัปดาห์/เดือน/ปี และกรองรายรับ/รายจ่าย/ทั้งหมด
- เพิ่มหนี้เอง กำหนดเดือนเริ่ม จำนวนงวด และดูตารางชำระรายเดือน
- ยืนยันงวดที่จ่ายแล้ว พร้อมเลขสลิปหรือภาพสลิปที่บีบอัดในเครื่อง
- ย้ายหนี้ที่จ่ายครบแล้วไปกล่องเก็บดูอย่างเดียว
- ลบหนี้ต้องพิมพ์ `confirm`
- Export/Import backup เป็นไฟล์ `.xanbackup` รวมข้อมูลและภาพสลิป
- ข้อมูลหลักเก็บเป็นไฟล์ JSON ในพื้นที่ private ของแอป ไม่ใช้ server และไม่ต้องต่ออินเทอร์เน็ตตอนใช้งาน

## เปิดโปรเจกต์

เปิดโฟลเดอร์ `finance_app` ด้วย Android Studio ที่ติดตั้ง Flutter plugin แล้วเลือกอุปกรณ์ Android จากนั้น Run

ถ้า `android/local.properties` ยังไม่มี ให้รัน `flutter pub get` หรือคัดลอกจาก `android/local.properties.example` แล้วแก้ path ของ Flutter/Android SDK ให้ตรงกับเครื่อง

แอปใช้ package id `com.xan.personal_finance` เพื่อให้ข้อมูลถูกเก็บไว้ในพื้นที่ของแอปบนเครื่อง

## ข้อควรระวังเรื่องข้อมูล

การอัปเดตแอปด้วย package id และลายเซ็นเดิมจะคงข้อมูลไว้ แต่การถอนการติดตั้งแอปจะลบข้อมูล private ของแอป ควร Export Backup เป็นระยะและเก็บไฟล์ไว้ใน Files/Drive/คอมพิวเตอร์ของคุณ
