## Future Plan

### ระบบหารค่าข้าว

ระบบสำหรับแยกค่าอาหารระหว่างกลุ่มเพื่อน โดยเมื่อเราเป็นผู้จ่าย ระบบจะบันทึกเป็น
Expense ก่อน และเมื่อเพื่อนโอนเงินคืน จะบันทึกเป็น Income โดยสามารถกำหนดได้ว่า
ส่วนของเราเองรับผิดชอบค่าอาหารเท่าไร

- แสดงยอดค่าอาหารทั้งหมด
- ปรับยอดอาหารที่แต่ละคนรับผิดชอบได้
- แสดงยอดที่แต่ละคนต้องจ่าย
- ติดตามสถานะว่าใครจ่ายแล้วหรือยังไม่จ่าย
- แบ่งส่วนลดให้แต่ละคนเป็นเปอร์เซ็นต์
- สร้างรายการ Expense/Income เชื่อมกลับเข้าหน้า Overview
